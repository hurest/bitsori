## 1. 한 문장

**"사진을 연주하는 장난감 악기."** 카메라를 대면 노래가 되고, 노래는 다시 무지개 줄이 달린 그림이 된다.

**롤모델: 오타마톤 (확정, 2026-10-28).** 목표는 정확한 변환 도구가 아니라 **오타마톤 같은 서비스**다.
- 한눈에 알아보는 모양, 한 번 들으면 아는 소리를 갖는다.
- 누구나 바로 갖고 논다.
- 사람들이 영상으로 퍼뜨린다.
- 만든 곳이 원조로 기억된다.

## 2. 오타마톤에서 배울 것

| 오타마톤의 힘 | 빛소리에서는 |
|---|---|
| **한눈에 알아보는 모양**: 음표 모양에 얼굴이 달림 | **무지개 줄 + 픽셀 그림**. 모든 빛소리 그림 맨 아래에 무지개 줄이 붙는다 (4장) |
| **한 번 들으면 아는 소리**: "와와~" 하는 목소리 같은 음색 | **대표 음색** 하나를 만든다. 소리만 들어도 빛소리인 것 |
| **누구나 바로 연주** | 카메라를 대면 끝. 라이브 모드(카메라가 악기), 그림을 손가락으로 쓸어 연주 |
| **완벽하지 않아서 사랑스러움** | 셀카·반려동물·음식 사진이 노래가 된다. "내 얼굴은 무슨 노래?" |
| **커버 영상 문화** | MIDI → 그림: 유명 곡을 그림으로 올리고 "무슨 노래게?" 맞히기. 찍으면 정답이 재생된다 |
| **한정판·협업 모델** | 유료 필터를 **에디션**으로: 아티스트 팩, 캐릭터 팩, 계절 한정 |
| **만든 사람이 원조로 남음** (메이와 덴키) | 메타정보 규격의 원조 + 무지개 줄 서명. 빛소리 그림은 어디서든 출처가 남는다 |

## 3. 정체성 3요소

1. **무지개 줄 (모양)**
   - 그림 맨 아래 한 줄이다. 메타정보를 담는 그릇이면서 브랜드 서명이다.
   - 프로젝트 코드명 "레인보우 스트링"이 그대로 제품의 상징이 된다.
2. **대표 음색 (소리)**
   - 후보: 노래하는 듯한 귀여운 신스 목소리, 실로폰과 오르골 사이의 맑은 음색.
   - 새로운 기본 필터로 만들지, 반주 위에 얹는 시그니처 효과로 만들지 정해야 한다.
3. **마스코트 (얼굴)** — 선택
   - 픽셀 캐릭터가 스캔선을 따라 걸으며 노래하는 식이다.
   - 공유 영상의 인트로와 아웃트로에 쓴다.

## 4. 무지개 줄

```
┌────────────────────────────┐
│                            │
│      노래 격자 (그림)        │
│                            │
├────────────────────────────┤
│▮▯ 🟥🟨🟩🟦 ▯▮▯▯▮▮▯▮▯▮▯ ▯▮│  ← 무지개 줄: 노래에 포함되지 않음
└────────────────────────────┘
  시작   색 기준     데이터    끝
```

- **노래 격자 바깥**의 한 줄이다. 읽는 쪽은 이 줄을 떼고 노래를 해석한다.
- **기준 색**(빨강·노랑·초록·파랑)이 무지개처럼 보인다. 압축으로 틀어진 색을 보정하는 기술 장치가 곧 브랜드다.
- **담는 것**: 노래를 정하는 핵심 설정 + 음 검증값.
  - 파일 내부 메타정보가 SNS에서 지워져도 노래를 되살린다.
- 자세한 형식은 [규격 초안 6장](spec/score-format-v1-draft.md#6-무지개-줄-보이는-그릇)에 있다.
- **QR 재생 링크** (선택)
  - 무지개 줄 끝에 작은 QR을 붙일 수 있다.
  - 휴대폰 기본 카메라로 찍으면 `bitsori.app`에서 바로 재생된다. 공유가 곧 유입이 된다.

## 5. 핵심 경험 (우선순위 재편)

정확한 변환 도구에서 **놀잇감**으로 무게를 옮긴다.

| 순위 | 경험 | 지금 상태 | 비고 |
|---|---|---|---|
| 1 | **찍으면 바로 노래** | ✅ 시제품 | 이미 핵심 동작 |
| 2 | **릴스·쇼츠 영상**: 픽셀이 소리에 맞춰 움직이는 9:16 영상을 앱에서 바로 업로드 (8장) | ❌ | 퍼지는 단위. **P1 → P0으로 올림** |
| 3 | **라이브 모드**: 카메라를 움직이면 소리가 바뀌는 "카메라 악기" | ❌ | 오타마톤의 "연주하는 재미". **P1 → P0으로 올림** |
| 4 | **"무슨 노래게?" 챌린지**: 유명 곡 → 그림 → 찍으면 재생 | 부분 (MIDI → 그림, 🎲 그림 뽑기) | 무지개 줄과 QR 재생이 붙으면 완성 |
| 5 | **필터 에디션**: 협업, 한정 필터 | 부분 (유료 필터 구조) | 수익 |
| 6 | **원조 규격 공개** | 초안 | 놀이로 유명해진 뒤 공개해야 원조로 기억된다 |

## 6. 퍼지는 고리

```
찍기 → 노래 + 무지개 줄 그림 → 공유 영상/이미지
   ↑                                   ↓
빛소리 설치 ← "나도 해볼래" ← 친구가 찍어서 재생 (QR / 무지개 줄)
```

- 공유된 그림은 **어떤 앱에서 열어도** 같은 노래다 (규격). 다만 **반주와 대표 음색은 빛소리에서만** 들린다.
- 유료 필터로 만든 작품도 **감상은 무료**다. 자기 사진에 쓰려면 구매한다.

## 7. 원조로 남는 전략 (요약)

- **노래는 개방, 소리는 빛소리**
  - 음을 정하는 규칙은 공개해서 누구나 재현하게 한다.
  - 반주 스타일·대표 음색·필터는 이름만 공개하고 실제 소리는 빛소리가 갖는다.
- **원조 표식**: 규격 주소를 빛소리 도메인에 둔다. 참조 구현과 기준 테스트 데이터를 공개한다. 호환 인증 마크와 상표를 확보한다. 자세한 내용은 [규격 초안 11장](spec/score-format-v1-draft.md#11-원조로-남는-장치)에 있다.
- **순서**: 놀이로 알려진다 → 무지개 줄이 "빛소리 그림"의 표식으로 자리 잡는다 → 규격을 공개해 다른 곳도 읽고 쓰게 한다.

## 8. 릴스·쇼츠 영상 (기록: 2026-10-28)

> 사진을 노래로 바꾸면서 **픽셀에 맞춰 소리가 나는 모습을 영상**으로 만들어, 앱에서 **릴스·쇼츠로 바로** 올린다.

**영상 구성 (9:16 세로)**

| 구간 | 장면 |
|---|---|
| 인트로 (1~2초) | 원본 사진 → 픽셀로 쪼개지는 전환 (찰칵 소리) |
| 본편 | 스캔선이 지나가며 지금 울리는 칸이 반응한다 |
| 아웃트로 (1~2초) | 빛소리 로고 + 무지개 줄 + "이 노래 만들기" QR/링크 |

**픽셀 모션 (소리와 1:1로 맞춘다)**

| 소리 | 움직임 |
|---|---|
| 울리는 칸 | 통통 튀어 오르고 빛남 |
| 음 높이 | 높은 음일수록 더 높이 튐 |
| 음 세기(채도) | 셀수록 크게 빛남 |
| 긴 음 | 빛이 꼬리처럼 이어짐 |
| 화음 | 같은 칸의 여러 줄이 함께 반응 |
| 베이스 | 화면 전체가 살짝 숨 쉬듯 커짐 |
| 드럼 | 킥은 바닥 흔들림, 스네어는 번쩍 |
| 쉼표 | 조용히 멈춤 |
| 마스코트 (선택) | 스캔선을 따라 걸으며 노래함 |
| 무지개 줄 | 화면 아래에서 재생 진행 막대 역할 |

**길이와 내보내기**
- **길이**: 15초 / 30초 / 60초 중 선택
- **곡이 길면**: 가장 소리가 풍성한 구간을 자동으로 골라 쓰거나, 빠르기를 올려 압축한다. 사용자가 구간을 조절할 수도 있다.
- **소리**: 재생하지 않고 바로 파일로 만든다 (오프라인 렌더링). 실시간보다 빠르다.
- **파일 형식**: MP4 (H.264 + AAC), 1080×1920, 30fps
- **바로 올리기**: 인스타그램 릴스 · 유튜브 쇼츠 · 틱톡 · 카카오톡 · 갤러리 저장
- **자동 문구 제안**: "내 사진의 노래 🎵 #빛소리 #Bitsori" + 필터·악기 이름

**기술 메모**
- 웹: 캔버스와 오디오를 MediaRecorder로 녹화 (WebM/MP4)
- 앱: 네이티브 인코딩(iOS AVAssetWriter, Android MediaCodec)을 Capacitor 플러그인으로 연결
- 공유: 각 서비스의 공유 기능(인스타그램 Reels 공유, Android 공유 인텐트 등)을 쓴다

**정책**
- 아웃트로의 로고와 무지개 줄은 기본으로 유지한다. 퍼지는 고리의 핵심이기 때문이다.
- 유료 기능으로 "로고 제거"를 팔지는 미정이다. 원조 표식과 충돌하므로 신중히 정한다.

## 9. 콜라보 아이디어

오타마톤처럼 **"빛소리 X ○○ 에디션"**을 만든다.
- 콜라보 필터: 그 IP의 색·코드 진행·대표 음색
- 프레임과 무지개 줄 디자인
- (선택) 실물 굿즈

| 분야 | 아이디어 | 왜 잘 맞나 |
|---|---|---|
| **K-POP 포토카드** ⭐ | 포토카드 뒷면이나 앞면 아래에 무지개 줄. 찍으면 그 멤버 사진의 노래(또는 곡 일부)가 재생된다. 앨범마다 멤버별로 다른 노래 | 이미 수집 문화가 있고, "내 포카는 무슨 노래?"라는 교환·인증 놀이가 생긴다 |
| **명화 시리즈** ⭐ | "명화가 부르는 노래": 고흐·모네 등 저작권이 끝난 작품. 미술관 굿즈, 전시 연계 | 라이선스 비용 없이 바로 시작할 수 있는 첫 콘텐츠. 교육·전시와도 연결된다 |
| **즉석 사진·포토부스** ⭐ | 인생네컷 같은 포토부스나 즉석 프린터로 뽑은 사진 아래에 무지개 줄. 찍으면 그날의 노래가 재생된다 | 실물 사진이 노래가 된다. 오타마톤처럼 "손에 잡히는" 물건이 생긴다 |
| **아티스트 앨범** | 앨범 커버가 연주하는 멜로디, 또는 타이틀곡 MIDI → 공식 "노래 그림" 한정판 프린트. 아티스트의 코드 진행·음색으로 만든 필터 | 팬덤 확산. "무슨 노래게?" 챌린지와 바로 연결된다 |
| **캐릭터 IP** (웹툰·애니·게임) | 캐릭터가 스캔선을 따라 노래하는 필터, 캐릭터 프레임 | 마스코트 효과를 빌려 온다. 아이·학부모층 |
| **픽셀 아트 게임** | 게임 스프라이트·맵이 노래가 된다. 사운드트랙 협업 | 픽셀이 본래 정체성인 분야라 결이 같다 |
| **음료·과자 패키지** | 한정판 캔·컵에 무지개 줄. 찍으면 그 맛의 노래 | 대량 노출되는 매체라 무지개 줄 인지도에 좋다 |
| **도시·관광·축제** | "서울 야경의 노래", 불꽃축제 필터, 관광지 사진 → 지역 노래 | 지자체·관광공사 예산과 맞닿아 있다 |
| **악기·음향 브랜드** | 그 브랜드 악기 샘플로 만든 공식 악기 팩 | 대표 음색의 품질을 끌어올린다 |
| **교육** | 초등 STEAM 교구: 그림 그리기 → 노래, 픽셀·음계 원리 | 꾸준한 B2B 수요 |
| **웨딩·스튜디오 사진** | 웨딩 사진이 우리 부부의 노래가 된다. 액자에 무지개 줄 | 기념일 감성, 높은 결제 의향 |

**추천 첫 순서**
1. **명화 시리즈**: 비용 없이 콘텐츠와 굿즈를 실험한다.
2. **포토부스·즉석 사진**: 실물 접점을 만들고, 무지개 줄이 실제로 찍히는지 실험한다.
3. **K-POP 포토카드**: 확산력이 가장 크다. 앞의 두 실험으로 품질이 증명된 뒤 제안한다.

**콜라보 공통 조건**
- 무지개 줄과 빛소리 로고 유지
- 콜라보 필터는 앱의 유료 에디션
- 실물 굿즈는 무지개 줄 인식률 테스트를 통과해야 출시
