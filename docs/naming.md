# 제품명 검토: 빛소리 / Bitsori

조사일: 2026-10-28

## 이름
- **빛소리** = 빛 + 소리. 사진(빛)이 노래(소리)가 된다는 뜻.
- **Bitsori**: 영문 표기에 "bit"(픽셀·비트)의 의미가 하나 더 붙는다.
- 프로젝트 코드명이었던 "레인보우스트링(Rainbow String)"은 내부 이름으로만 쓴다.

## 다른 언어에서의 뜻
| 언어 | 결과 | 위험도 |
|---|---|---|
| 한국어 | 빛소리와 빗소리는 둘 다 [빋쏘리]로 발음된다. 말로 들으면 "비 소리"로 알아듣기 쉽다 | 낮음 |
| 영어 | "a bit sorry"로 들릴 여지가 있다. 비속어 뜻은 찾지 못했다 | 낮음 |
| 스페인어(중남미) | 앞부분이 멕시코 1위 암호화폐 거래소 **Bitso**와 같다 | 주의 |
| 중국어 | 比索(bǐsuǒ)는 "페소"라는 뜻이다. 逼(bī)는 비속한 뉘앙스가 있으니 피한다 | 주의(한자 선택) |
| 프랑스어 | 첫 음절 bit가 비속어 bite와 비슷하지만, 단어 전체로는 연상이 약하다 | 낮음 |
| 일본어 | そり는 썰매라는 뜻으로 무해하다 | 낮음 |
| 타갈로그어 | bitso는 튀김과자라는 뜻으로 무해하다 | 없음 |
| 인도네시아어 | sori는 구어체로 "미안"이라는 뜻이다 | 낮음 |
| 그 밖의 언어(포르투갈어·독일어·이탈리아어·태국어·베트남어·힌디어·아랍어·러시아어·튀르키예어) | 문제가 될 만한 뜻을 찾지 못했다 | 없음~낮음 |

**결론**: 조사한 언어 어디에서도 비속어나 불길한 뜻은 확인되지 않아, 쓸 만한 이름이다. 주의할 점은 아래 세 가지다.
- 로고와 영문 표기를 **Bit·Sori / BitSori**처럼 끊어 써서 Bitso 연상과 "bit sorry"로 읽히는 문제를 줄인다.
- 중국어 이름은 比索를 피하고 따로 정한다(예: 光之声).
- 출시 전에 KIPRIS(한국)·USPTO(미국)·IMPI(멕시코)·WIPO에서 9류(소프트웨어)와 41류(엔터테인먼트) 상표를 조회한다. 웹 검색에서는 동명 앱·회사를 찾지 못했다.

## 발음과 표기 가이드 (2026-10-28)

### 외국에서 읽기
철자는 쉽다. 알파벳 7자에 특이한 조합이 없다. 다만 **어디서 끊어 읽느냐**가 언어권마다 갈린다. 아래 발음 예상은 판단이며, 출시 전 테스트로 확인해야 한다.

| 언어권 | 예상 발음 | 의도("빛소리")와 비교 |
|---|---|---|
| 스페인어·이탈리아어·포르투갈어 | 빗-소-리 | ✅ 거의 그대로 |
| 독일어·프랑스어 | 빗-소-리 | ✅ 대체로 그대로 |
| 영어 | 빗-쏘-리 / 빗 쏘리 | ⚠️ "a bit sorry"처럼 들릴 수 있음 |
| 일본어 | ビツォリ(비초리) | ⚠️ 일본어의 "ts" = つ(츠) 소리 → "비-초리"가 되기 쉬움 |
| 중국어 | 음역 표기가 따로 필요 | 比索(bǐsuǒ, '페소')는 피한다 |

### "sori"를 받아들이는 방식
- **대다수**: 뜻은 모르고 어감으로 받아들인다. "bit"는 픽셀·디지털 느낌으로 바로 통하고, "sori"는 부드럽고 이국적인 느낌을 준다.
- **영어권 일부**: "sorry"를 떠올린다. 부정적이기보다는 가벼운 말장난에 가깝다. 인도네시아어 sori도 구어체로 "미안"이다.
- **한국 문화에 관심 있는 사람**: 판소리(pansori, 유네스코 무형문화유산)를 통해 "sori = 소리/노래"를 알아본다.
- **오타마톤과 같은 구조**다. 오타마톤 = 일본어 "오타마자쿠시(올챙이, 음표의 별명)" + 영어 "tone". 외국인 대부분은 뜻을 몰랐지만 어감과 모양으로 사랑받았다. Bitsori도 **"아는 영어 단어 + 모르는 모국어 단어"** 공식이다.

### 표기 원칙
1. **영문 로고·표기: BitSori 또는 Bit·Sori**
   - 끊어 읽는 위치가 보이게 해서 "bit sorry"·"Bitso"로 읽히는 문제를 줄인다.
   - 일반 문장 안에서는 Bitsori로 써도 된다.
2. **영문 발음 안내 (고정 문구)**
   > Bitsori (bit-so-ree): "bit" as in pixels, "sori" is Korean for sound.
3. **나라별 표기**

   | 언어 | 표기 | 이유 |
   |---|---|---|
   | 한국어 | 빛소리 | |
   | 일본어 | **ビットソリ** (빗토소리) | "bit + sori"로 끊어 읽게 하고, 비초리로 읽히는 것을 막는다 |
   | 중국어 | **比特声** (bǐtè shēng) 또는 **光之声** | 比特는 중국어에서 "비트"의 표준 표기다. 比索(페소)는 쓰지 않는다 |

4. **"sori"를 우리 단어로 키운다**
   - "Make a sori", "Every pixel has a sori."처럼 sori를 제품 용어로 계속 쓴다.
   - 목표는 kawaii·emoji처럼 빛소리가 세상에 가르친 단어가 되는 것이다. ([컨셉 11장 "이름 선점"](concept.md))

### 출시 전 확인
- **발음 테스트**: 영어·일본어·스페인어 사용자 각 5~10명에게 이름만 보여 주고 소리 내어 읽게 한다. 어디서 끊는지, 무엇이 떠오르는지 기록한다.
- 결과에 따라 영문 표기(Bitsori / BitSori / Bit·Sori)와 일본어 표기를 확정한다.
